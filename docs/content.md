# Контент

Единый каталог находится в `packages/content` и используется всеми клиентами. При импорте
коллекция проходит Zod-валидацию, поэтому невалидный материал не попадает даже в локальную
сборку.

## Поддерживаемые типы

- `term` — термин и определение;
- `flashcard` — вопрос и развёрнутый ответ;
- `single_choice` — один правильный вариант;
- `multiple_choice` — несколько правильных вариантов;
- `code_output` — определение результата выполнения кода;
- `find_bug` — поиск причины и исправление;
- `interview_question` — открытый вопрос с rubric и reference points.

## Обязательные инварианты

- стабильный `id` формата `topic-readable-slug-001`;
- положительная версия;
- непустые `prompt` и `explanation`;
- уникальные id и теги;
- все `correctOptionIds` существуют в `options`;
- каждый code block имеет `language`;
- markdown fences парные;
- `relatedIds` ссылаются только на существующие материалы и не на сам материал.

## Проверка

```bash
corepack pnpm@9.15.4 content:validate
```

Команда выводит количество материалов по темам и завершает процесс с ненулевым кодом при
любой ошибке. Она также входит в корневой `pnpm check`.

Сейчас каталог содержит 60 материалов: по 10 для JavaScript, TypeScript, React, Browser,
Node.js и CSS.

## Теоретическая база

Отдельный каталог `packages/content/src/theory-catalog.ts` содержит самостоятельные учебные
главы. Сейчас подготовлено 18 материалов — по три для каждой поддерживаемой темы:

- замыкания JavaScript;
- generics TypeScript;
- reconciliation и `key` в React;
- CORS в браузере;
- event loop Node.js;
- Flexbox.

Второй набор охватывает Promise-цепочки, mapped types, очередь state-обновлений React, Web
Storage, ES modules в Node.js и CSS Grid.

Третий набор разбирает делегирование DOM-событий, conditional types, границы React Context,
critical rendering path, память Node.js/V8 и CSS cascade со specificity.

Каждая глава хранит краткое введение, разделы, полностью редактируемый пример кода, объяснение,
ключевые тезисы и ссылки. Схема требует хотя бы один первичный технический источник и проверяет
уникальность `id`, `slug` и внешних source ID. Поэтому новую главу можно добавить в каталог и
сразу проверить общей командой `content:validate`.

Текст и код этих 18 глав написаны специально для проекта. Они не являются копиями или
перефразированными версиями статей Hack Frontend. Ссылка на соответствующую страницу используется
для атрибуции темы, а технические утверждения сверяются с официальной документацией.

Пользователь открывает базу в web-разделе «Теория»: каталог загружается отдельно от полной главы,
поддерживает поиск, фильтрацию по темам, прогрессу и закладкам. Открытие главы переводит её в
`reading`; пользователь может независимо добавить её в закладки и отметить прочитанной. Это
состояние хранится в SQLite и восстанавливается после перезагрузки. Экран чтения показывает
разделы, code block, ключевые тезисы и атрибутированные ссылки без интерпретации произвольного
HTML. Каждая глава также хранит от одного до трёх `relatedContentIds`: интерфейс создаёт из них
отдельную practice-сессию по кнопке «Тренировать тему», не изменяя дневную очередь.

## Внешняя база источников

Hack Frontend используется как reference-only каталог для поиска тем и проверки покрытия. Команда
читает только публичный официальный sitemap и сохраняет метаданные русскоязычной документации:
`id`, раздел, slug и URL.

```bash
corepack pnpm@9.15.4 content:sources:sync
```

Тексты статей, примеры кода, ответы и квизы не копируются. У сайта не указана открытая лицензия на
переиспользование материалов, поэтому новые карточки пишутся самостоятельно. Перед публикацией
технические утверждения дополнительно сверяются с первичным источником: спецификацией, MDN или
официальной документацией фреймворка. Ссылка Hack Frontend сохраняется как атрибуция и направление
для дополнительного чтения.

В content package доступны `hackFrontendKnowledgeBase`, `getKnowledgeSourceStats()` и
`searchKnowledgeSources(query, { topic })`. Синхронизация выполняется вручную; обычные build и
тесты не зависят от сети и валидируют уже сохранённый snapshot.

## Mock-интервью

Отдельный каталог содержит шесть наборов: Frontend Core, React, JavaScript Deep Dive, Browser,
Node basics и React Native. Набор хранит стабильный порядок ID открытых вопросов, рекомендуемую
длительность и версию. Каждый вопрос содержит эталонные тезисы и ссылки на существующие учебные
материалы. После оценки `again` или `hard` эти связанные материалы попадают в ближайшее
интервальное повторение пользователя. CLI проверяет уникальность ID, целостность наборов и наличие
всех связанных карточек.
