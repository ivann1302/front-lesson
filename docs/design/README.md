# Визуальное направление

Актуальный layout-концепт: [modern-dashboard-concept.png](modern-dashboard-concept.png),
сгенерирован по скриншоту рабочего продукта. Предыдущий вариант
[today-concept.png](today-concept.png) сохранён как история направления.

## Инвентарь концепта

- Тёмный компактный rail: wordmark FM.Mentor, четыре раздела, карточка дневной цели внизу.
- Первый viewport: приветствие и серия сверху; центральная дневная сессия занимает главный
  визуальный вес; справа находятся повторения и успеваемость.
- Главный CTA — «Продолжить»; вторичное действие — просмотр следующего задания.
- Палитра: тёплый почти белый фон, charcoal `#111923`, cobalt `#155eef` и точечный
  acid-lime `#b7eb26` для прогресса и завершённых состояний.
- Типографика: строгий гротеск, технические фрагменты — monospace.
- Геометрия: радиус 18–25 px, мягкие поверхности, спокойные тени; градиент используется
  только для глубины rail и главного действия.
- Десктоп: rail + основная колонка + контекстная колонка. Мобильный вид сохраняет header,
  CTA и прогресс, а навигация становится нижней.
- Рабочий сценарий подключён к API: сайт восстанавливает гостя, загружает дневную очередь,
  отправляет ответ и восстанавливает прогресс после перезагрузки;
  объяснение обновляет прогресс; «Следующее» возвращает к очереди или следующему вопросу.

UI реализуется кодом как адаптивный сайт. Растровый концепт используется только как
спецификация и не выводится в интерфейсе. Установка PWA и Service Worker намеренно не
добавляются; React Native будет отдельным клиентом на следующем продуктовом этапе.
